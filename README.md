# PRAXIS_WEBSITE

The Praxis Studio website — a design-first studio, "Theory made real."
The site is a faithful re-skin of bitwip.fr in the Praxis brand, built
by Claude from the docs in this repo.

## For Claude — start here
You have everything. Nothing needs to be uploaded or sent to you.
Read, in this order:
1. `docs/01-BRAND-BOOK-v5.pdf` — logo plates, colours, type, rules (visual bible)
2. `docs/02-CONTEXT-AND-VISION.md` — who we are, the vision, what's locked, what's yours to decide
3. `docs/03-PROMPT-for-Claude.md` — the master prompt (the block between the COPY lines)
4. `docs/04-WORK-GENERATION.md` — the 16 portfolio projects to generate
5. `docs/assets/` — original brand guidelines, reference pages, the Handjet font, earlier HTML sketches (ideas only)
6. Reference site: https://www.bitwip.fr/en — study it live

Build the complete website into this repo's root and commit your
work. `docs/` is the prereq package — never overwrite it. You have
the final say (the docs say so): decide everything, ask for nothing,
ship complete.
