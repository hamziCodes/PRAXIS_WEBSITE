# PRAXIS_WEBSITE

The Praxis Studio website — a design-first studio ("Theory made real."),
built as a faithful re-skin of bitwip.fr in the Praxis brand.

## Start here (for Claude)
Feed the files in this order:
1. `docs/01-BRAND-BOOK-v2.pdf` — logo plates, colours, type (see note below)
2. `docs/02-CONTEXT-AND-VISION.md` — who we are, vision, locked decisions
3. `docs/03-PROMPT-for-Claude.md` — the master prompt (copy between the lines)
4. `docs/04-WORK-GENERATION.md` — the 16 concept projects to generate
5. `docs/assets/` — original guidelines, reference pages, Handjet font, HTML sketches (ideas only)
6. Reference site: https://www.bitwip.fr/en

Claude has the final say — the docs say so. Build the site in this
repo's root; `docs/` is the prereq package, do not overwrite it.
