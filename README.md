## What this site is

Praxis Studio is a new, three-person studio: **Hamza, Laiba and Shahzaib**. The same people who sit in the first meeting design the identity, build the site and read the campaign numbers. This website is the studio's shop window, and it has four jobs:

- **Say what the studio does,** in plain words: strategy & consulting, brand & creative, web & digital, campaigns & media.
- **Prove it with work.** Sixteen full case studies, four per service. Each one opens with the client's question, then gives the challenge, solution, results, a headline metric, a gallery and a client testimonial.
- **Show how the studio thinks,** through a journal and a 48-term glossary written in the studio's own voice.
- **Make starting easy:** a live Islamabad clock with open/closed status, one email address everywhere (hello@praxis.studio) and a short project form.

The layout follows a proven editorial agency structure. Everything is re-skinned in the Praxis brand: light Bone pages, black type, a single Inchworm accent, and the pixel as the brand's graphic signature.

## Signature moments

| | |
|---|---|
| **Pixel snake** | A grid-snapped trail of pixels roams the hero, dragging the word pills BRANDING · UIUX · MOTION · SEO. It chases your cursor. |
| **Headline pixel break** | As you scroll away, *Theory made real.* breaks into drifting blocks, then reassembles on the way back. |
| **Pixel assemble** | Every project image builds itself from chunky pixels as it scrolls into view. |
| **The trifecta** | The people behind the work, as giant names. No titles, anywhere. |
| **Live studio clock** | Islamabad time with OPEN / CLOSED status, plus a line telling you the time where you are. |
| **Services accordion** | A dark panel where each service has its own star colour, and the case-study visual swaps as you open each one. |
| **Drag carousel** | Featured work you can throw sideways with momentum. It also works with touch and arrow keys, and includes a metric card. |

## Brand system

<p align="center"><img src=".github/readme/palette.svg" alt="Praxis palette: Bone, Black, Inchworm, Gunmetal, Bright Snow, American Silver, Orange, Pale Violet" width="100%"></p>

| Role | Choice |
|---|---|
| **Logo** | Pixel starburst mark plus a wordmark whose **x is a chunky 4-petal star**. Traced from the brand plates and shipped as one reusable SVG component. |
| **Main type** | Helvetica Neue, falling back to TeX Gyre Heros (a free Helvetica-class face) so the site looks the same on Windows and Android. |
| **Pixel labels** | Handjet, used only for tags, kickers and word pills. |
| **Display word** | Instrument Serif Italic, exactly one word inside a big headline. |
| **Colour rules** | Light Bone pages, black text, Inchworm as the single accent. Gunmetal only for galleries and closing panels. Orange and Pale Violet only as sparks inside imagery. Never more than two accents on one screen. |

## Stack

| Layer | What's used | Why |
|---|---|---|
| **Pages** | Hand-written semantic HTML5, generated by a zero-dependency Node script (`src/build.mjs`) | Fast, cacheable, works on any host, and content lives in plain data files |
| **Styles** | One CSS file with design tokens in custom properties. Fluid `clamp()` type, CSS Grid, `:has()`, `backdrop-filter` | No framework weight, one system |
| **Motion** | Vanilla JavaScript: `IntersectionObserver`, `requestAnimationFrame`, Canvas 2D for the snake and pixel effects | Every effect is progressive: content is fully visible without JS |
| **Smooth scroll** | [Lenis](https://github.com/darkroomengineering/lenis), self-hosted and optional | If it fails to load, native scrolling takes over |
| **Artwork** | `src/art.mjs`, a procedural SVG generator for 16 client logos and 146 project images | Crisp at every size, tiny files, consistent art direction |
| **Logo** | Python + fontTools outline the wordmark; the star-x and mark are drawn from plate measurements | Production vector, identical everywhere |
| **Fonts** | Self-hosted woff2, subset with fontTools | No third-party font requests |
| **SEO** | Canonicals, Open Graph, `sitemap.xml`, JSON-LD (Organization, Article, DefinedTermSet) | Ready for search engines and answer engines |
| **Security** | Strict Content-Security-Policy on every page, `_headers` with HSTS, `frame-ancestors`, nosniff and Permissions-Policy | No inline scripts, no third-party hosts |
| **Hosting** | Any static host: Netlify, Cloudflare Pages, Vercel, GitHub Pages | Point it at the repo root; no build step on the server |

**Quality bar:**
- Responsive from 320px up. The header pill never wraps.
- Full keyboard support and visible focus rings.
- `prefers-reduced-motion` respected everywhere.
- A preloader that dismisses itself even if every script fails.

## Run it locally

```bash
git clone https://github.com/hamziCodes/PRAXIS_WEBSITE.git
cd PRAXIS_WEBSITE
node src/tools/serve.mjs        # http://localhost:4321
```

Edit content, then rebuild (Node 20+):

```bash
node src/build.mjs
```

## Project structure

```
index.html  services/  work/  about/  journal/  glossary/  contact/  404.html
assets/
  css/site.css            design tokens + all styles
  js/site.js              interactions and motion
  fonts/  logo/  img/     self-hosted fonts, logo SVGs, generated artwork
src/
  data/projects.mjs       the 16 portfolio projects (one self-contained block each)
  data/services.mjs       the four services
  data/journal.mjs        articles, FAQ, glossary
  art.mjs  logo.mjs  build.mjs
docs/                     the original brand brief package
```

**To change a project:** edit its block in `src/data/projects.mjs` and rebuild. Its case page, cards, logo-wall entry and testimonial all update together. To use real photography instead of generated art, drop the files in `assets/img/work/<slug>/` and list them under `images`. More detail is in [DELIVERY-NOTES.md](DELIVERY-NOTES.md).
